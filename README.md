Лабораторная работа №1

Веб-приложение для работы с цветовыми моделями CMYK, LAB и HSV.

Что есть

- изменение цвета через поля, ползунки и палитру;
- автоматический пересчёт CMYK, LAB и HSV;
- динамические градиенты на всех ползунках;
- ручные формулы преобразования без библиотек конвертации;
- D65, D50 и E;
- GCR и UCR;
- Clipping и Scaling;
- предупреждение при выходе цвета за диапазон RGB;
- разделение кода на Model / Controller / View;
- автоматические тесты математических функций.

RGB используется только как промежуточная модель для расчётов и отдельно в интерфейсе не отображается.

Структура

src/
├── model/ # математические расчёты

├── controller/ # логика и состояние

├── view/ # интерфейс

└── tests/ # тесты

Матрицы RGB ↔ XYZ рассчитываются программно в зависимости от выбранного освещения, поэтому в интерфейсе они не выводятся.

Запуск

npm install
npm run dev

Тесты:

npm test

# Color Lab — лабораторная работа 1

Учебное Next.js-приложение для ручного преобразования **CMYK ↔ LAB ↔ HSV**.

## Что реализовано

- три модели, требуемые для варианта: **CMYK, LAB, HSV**;
- изменение цвета через точные числовые поля, нативную палитру и ползунки;
- автоматический пересчёт всех трёх моделей при изменении любой координаты;
- динамические градиенты **на каждом ползунке**: цветовая заливка меняется по всему диапазону, пока остальные координаты остаются текущими;
- ручные математические преобразования без внешних библиотек конвертации;
- RGB используется только как внутренний промежуточный цветовой носитель для связи моделей, но не является отдельной моделью интерфейса;
- D65, D50 и E с динамическим построением матриц RGB ↔ XYZ и соответствующей белой точки;
- Clipping и Scaling при выходе промежуточного RGB за допустимый диапазон;
- GCR и UCR для цветоделения CMYK;
- ненавязчивое предупреждение при выходе LAB за RGB-гамут;
- разделение на Model (`lib/color.ts`), Controller/ViewModel (`lib/color-controller.ts`) и View (`app/page.tsx`, CSS);
- автоматические микро-тесты математики.

## Запуск

```bash
npm install
npm run dev
```

Проверка математических тестов:

```bash
npm test
```

Открыть `http://localhost:3000`.

# Color Lab — лабораторная работа 1

Учебное Next.js-приложение для ручного преобразования **CMYK ↔ LAB ↔ HSV**.

## Что реализовано

- три модели, требуемые для варианта: **CMYK, LAB, HSV**;
- изменение цвета через точные числовые поля, нативную палитру и ползунки;
- автоматический пересчёт всех трёх моделей при изменении любой координаты;
- динамические градиенты **на каждом ползунке**: цветовая заливка меняется по всему диапазону, пока остальные координаты остаются текущими;
- ручные математические преобразования без внешних библиотек конвертации;
- RGB используется только как внутренний промежуточный цветовой носитель для связи моделей, но не является отдельной моделью интерфейса;
- D65, D50 и E с динамическим построением матриц RGB ↔ XYZ и соответствующей белой точки;
- Clipping и Scaling при выходе промежуточного RGB за допустимый диапазон;
- GCR и UCR для цветоделения CMYK;
- ненавязчивое предупреждение при выходе LAB за RGB-гамут;
- архитектурное разделение по файлам: Model (`src/model/`), Controller/ViewModel (`src/controller/`) и View (`src/view/`); `app/page.tsx` только собирает приложение и хранит состояние интерфейса;
- автоматические микро-тесты математики.

## Запуск

```bash
npm install
npm run dev
```

Проверка математических тестов:

```bash
npm test
```

Открыть `http://localhost:3000`.

Финальная версия: три модели CMYK, LAB и HSV расположены в один ряд; матрицы пользователю не выводятся.


## Соответствие методическим формулам

Математика RGB↔XYZ↔LAB реализована вручную по формулам из методических материалов: sRGB-коррекция с порогом 0.04045, построение XYZ через матрицу, функция LAB с порогом 0.008856 и обратная функция. Для D65/D50/E матрица RGB↔XYZ строится заново из координат примариев sRGB и xy-координат выбранной белой точки, поэтому матрица не является жёсткой константой.

Для базового GCR используется формула цветоделения из методических материалов:
`K = min(1-R, 1-G, 1-B)`, затем `C = (1-R-K)/(1-K)`, `M = (1-G-K)/(1-K)`, `Y = (1-B-K)/(1-K)`.
UCR реализован как ограниченное удаление серой компоненты в тенях с сохранением обратимости CMYK→RGB.

Матрицы преобразования в интерфейсе **не отображаются**: они являются внутренними данными математической модели.
